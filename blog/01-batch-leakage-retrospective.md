# 一次"100% 准确率"的翻车复盘：跨平台基因表达分类里的批次泄漏

> 标签：机器学习 / 深度学习 / 数据泄漏 / 生物信息学
> 项目地址：[GeneTransformer](https://github.com/jsidj306/GeneTransformer)
> 系列：第 1 篇 / 共 3 篇

---

## 一个"完美"到可疑的结果

几周前我在做一个基因表达分类项目：输入患者的基因表达谱（一个「样本 × 基因」的数值矩阵），输出他属于哪种癌症（乳腺癌 BRCA / 肺癌 LUAD / 结直肠癌 COAD）。

第一版跑完，结果漂亮得离谱：

| 指标 | 数值 |
|---|---|
| 测试准确率 | 100% |
| macro-F1 | 1.0000 |
| 5 折 CV 标准差 | 0% |
| ROC-AUC | 1.0000 |

准确率 100%、标准差 0%，放到哪都是一等奖。但恰恰是「标准差 = 0%」这个细节出卖了它——一个真实、有噪声的生物数据，怎么可能每一折都一模一样？

## 根因：batch == class

问题出在数据上。我用的是三个公开的 GEO 数据集：

| 数据集 (GSE) | 癌种 | 平台 / 实验室 |
|---|---|---|
| GSE45827 | BRCA | 平台 A |
| GSE31210 | LUAD | 平台 B |
| GSE39582 | COAD | 平台 C |

看第一列和第三列：**每个数据集恰好只对应一种癌症**。也就是说，「来自哪个平台」和「是什么癌」是 1:1 混叠的——`batch == class`。

模型根本不需要学任何生物学知识，它只要学会「这个样本来自平台 B」，就能 100% 猜对它是 LUAD。

再叠加三个放大因素，泄漏就坐实了：

1. **随机划分**：`train_test_split` 让同一个 GSE 的样本同时进训练集和测试集，模型背平台分布即可满分。
2. **全局归一化泄漏**：z-score 和 top-5000 高变基因是在「合并后的全量矩阵」上算的，训练集偷看了测试集的统计量。
3. **量纲不一致**：LUAD 是线性表达（max≈53813），BRCA/COAD 是 log2（max≈16），没统一就合并，放大了平台差异。

## 怎么证明是假的：三条证据

我没有停留在"怀疑"，而是做了三件事把泄漏钉死。

**证据 1：批次身份可被平凡预测。** 训练一个「这个样本来自哪个 GSE」的分类器，准确率 1.0——表达谱能 100% 区分平台，这本身就是泄漏的指纹。

**证据 2：随机划分对照组。** 用当初产生 100% 的随机划分设置，RF 和 SVM 都是 macro-F1 = 1.0。

**证据 3：LODO 崩到随机。** 换成留一数据集（Leave-One-Dataset-Out）：每次留出一个完整平台做测试（一个模型从没见过的癌种），RF 和 SVM 全部掉到 **macro-F1 = 0.0**。

```text
随机划分（泄漏）:  macro-F1 = 1.0000
LODO（诚实）:     macro-F1 = 0.0000   ← 留出的全新癌种，模型认不出来
```

第三条是最狠的：模型不是"学会分癌"，它只是"记住了平台"。一旦留出的平台没见过，它只能把样本硬判给训练时见过的类别，于是全错。

## 我学到的四件事

1. **「完美到不真实」的指标先怀疑泄漏，再庆祝。** 100% / std=0% 是红灯，不是绿灯。
2. **跨数据集 / 跨批次任务必须用 LODO 或 grouped split**，随机划分在 batch==class 时是自欺欺人。
3. **任何跨样本统计量（z-score / 高变基因 / ComBat）只在训练集拟合**，再 apply 到测试集。
4. **看指标要看对。** 类别不平衡时 accuracy 会骗人，macro-F1、AUC 才是诚实的。

## 负结果也是结果

这件事没有白做。它把一个虚假的 100% 变成了一个**方法学结论**：仅凭这三个平台，跨平台的"多分类癌症识别"在数据层面就不可行。这个负结果直接决定了项目后来的走向——把任务从"哪种癌"降级成"是不是癌"（肿瘤 vs 正常），后者在三个平台里信号真实存在且能跨平台泛化（AUC 0.94–0.98）。

完整的泄漏诊断（PCA 批次投影、ComBat 对照、修复后的 LODO 协议）都在项目的[技术报告](https://github.com/jsidj306/GeneTransformer)里。
